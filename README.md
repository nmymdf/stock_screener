# 台股選股

台股的選股工具 App，是 [stock_acc（股票記帳）](https://github.com/nmymdf/stock_acc)
README 裡規劃的「個股分析，另一個獨立模組」。技術選股、今日雷達這些功能
獨立成一個 App，放在這個 repo。

跟 stock_acc 一樣用 Flutter 寫，同一份程式碼可以編譯成 **Windows 版**和
**Android 版**。資料只存在裝置本機，不會上傳到任何雲端伺服器。

程式碼在 [`app/`](app) 資料夾。

> **這是機械化的條件篩選和排序，不是投資建議、也不是預測。** 沒有任何指標
> 組合能保證篩出來的股票之後會賺錢，只是幫忙從兩千多檔裡縮小範圍，最終判斷
> 還是要使用者自己來。每個選股畫面上都會顯示這個提醒。

## 功能

依照 MultiCharts 台股自動交易系統規格書 V1.0 的「市場 → 產業 → 個股 → 交易計畫」
架構，實作其中**用每日收盤行情就能做的部分**。每天收盤後分析全部上市櫃股票：

| 分頁 | 內容 | 規格書 |
| --- | --- | --- |
| **推薦** | 通過所有一票否決、依總分排序的股票。每一檔都寫出推薦理由（為什麼選它／要注意什麼）、交易計畫（可接受最高買價、停損、目標、報酬風險比、建議張數）。也可以切換看「有訊號但被否決」的股票和否決原因 | §9、§10、§11、§12 |
| **持股** | 記錄我買了哪些股票，每天收盤後自動判斷每一檔要「保留、注意、建議出場、停損」，並寫出理由；停損只會往上調；只加贏家、虧損加碼會警告；記錄賣出後累積成自己的交易紀錄與績效 | §12 |
| **市場** | Market Score（0～100）、五種市場狀態與建議最大曝險、分數逐項組成、市場廣度（站上均線比例、新高新低、漲跌停家數）、大型股 vs 中小型股、上市 vs 上櫃、歷史走勢圖 | §2 |
| **產業** | 34 個產業的強弱分數與輪動分類（領先／改善／同步／轉弱／落後），點進去看產業內個股 | §3 |
| **回測** | 用本機歷史資料驗證「推薦用的同一套規則」：勝率、平均 R、Profit Factor、最大回撤、前段／後段比較、壓力測試、Monte Carlo 回撤、出場原因、交易明細 | §15 |
| **工具** | 系統方法說明、資金與風險設定、自訂條件篩選、今日即時雷達（stock_acc 的選股雷達）、資料管理 | §11、§19 |

### 持股追蹤（§12）

- **新增持股**：自己輸入（代號、日期、價格、股數），或在個股報告按「我已進場」，自動帶入推薦時的停損、目標和理由。
- **持有方式**決定停損與出場規則：

  | 方式 | 停損 | 出場 | 時間停損 |
  | --- | --- | --- | --- |
  | 短線（1～3 週） | 進場價 − 2 ATR（或推薦停損） | +1R 保本；2R 先賣一半，剩下「最高價 − 3 ATR」移動停利 | 10 天沒有 +1R |
  | 波段（1～3 個月） | 進場價 − 2.5 ATR（或推薦停損） | +1R 保本，之後移動停利一路抱住 | 無 |
  | 長期（一季以上） | 虧損 15% | 收盤連續 3 天跌破季線且季線下彎；跌破年線提醒 | 無 |
  | 自己設定 | 自己填 | 碰到自己填的目標價 | 無 |

- **每天的狀態**：🔴 停損、🔵 建議出場（移動停利、保本、時間停損、到目標先賣一半、長期趨勢轉弱）、🟡 注意（快到停損、市場或產業轉弱、過熱）、🟢 保留。需要處理的排最上面。
- 從買進那天一天一天模擬規則，停損只會往上調；除權息後成本跟著還原，不會被假跌幅觸發。
- **只加贏家**：已經賺 ≥ 1R 又出現新的進場訊號才提示可以加碼；虧損時加碼會警告「禁止向下攤平」，要勾選確認才能記錄。
- 損益扣手續費 0.1425%（最低 20 元）和證交稅；全部賣出後列入交易紀錄（勝率、平均賺賠、已實現合計）。
- 只是提醒，不會自動下單；判斷用收盤價。

### 個股評分（§7、§8、§10.1）

| 模組 | 權重 | 內容 |
| --- | --- | --- |
| 趨勢 | 15 | 收盤相對 EMA20／50／100／200、多頭排列、EMA50 斜率、ADX＋DI、MACD |
| 相對強度 | 10 | 20／60／120／250 日報酬加權的全市場排名 |
| 動能 | 10 | RSI 順勢解讀（50～75 最健康，不採用「低於 30 必買」）、ROC、MACD 柱、KD（只作輔助） |
| 量價 | 10 | 上漲日量 vs 下跌日量、OBV、價漲量增、回檔量縮 |
| 突破 | 5 | 20／60／250 日新高、離 52 週高點距離 |
| 波動／型態 | 5 | 布林帶寬低分位、ATR% 下降、NR7、Inside Bar |
| 市場 | 10 | Market Score |
| 產業 | 10 | Industry Score |
| 基本面 | 15 | **尚未接資料**，不列入（權重重新分配） |
| 籌碼 | 10 | **尚未接資料**，不列入 |

### 進場訊號（§9）

- **A 突破型**：20 日窄幅整理後放量（≥ 1.5 倍）突破 20 日高點，在 50／200 日線之上，RS 前 30%。
- **B 回檔型**：強勢股回檔碰到 20／50 日線、量縮、RSI 回落到 35～52 後站回 50、收盤過昨高，RS 前 30%。
- **C 趨勢延續型**：前段已漲 ≥ 20%，10 天平台整理守在 50 日線上，再放量突破，RS 前 20%。
- **D 均值回歸型**：只在震盪盤；超跌後停止破底、重新轉強，目標回到 20 日線。

### 一票否決（§10.2）與交易計畫（§11、§12、§14）

- 否決：流動性不足（20 日均成交值 < 3,000 萬或均量 < 300 張）、市場空頭、歷史不足、
  合理停損過寬（> 3 ATR 或 10%）、報酬風險比不足（到目標或上方前高 < 2R）、總分未達
  目前市場狀態的門檻、RS／趨勢未達策略要求。
- 停損用結構停損（突破點、回檔低點、平台低點），目標 2R 先出一半，+1R 保本，
  之後「22 日最高 − 3 ATR」移動停利，10 天沒有 +1R 就時間停損。價格都對齊台股 tick。
- 張數 = 可承受損失 ÷ 每股風險（含滑價），受單檔曝險上限限制；帳戶回撤越大自動降低風險。
- 隔天開盤超過「收盤 + 0.5 ATR」就不追；收漲停會提醒可能買不到。

### 回測怎麼避免自己騙自己（§15）

- 推薦和回測呼叫同一組函式；第 t 天收盤出訊號、t+1 天開盤才進場。
- 每天的全市場名單就是那天真的有交易的股票（含之後下市的），沒有存活者偏差。
- 扣手續費、證交稅、滑價；跌停鎖死那天賣不掉；開盤就跌到停損附近的訊號不進場。
- 參數固定、沒有拿資料最佳化；附前段／後段、壓力測試（滑價 ×2、成本 ×1.5、晚一天進場）、
  Monte Carlo 最大回撤。用完全隨機的價格測試，平均每筆約 0R（沒有憑空變出優勢）。
- 限制：逐筆訊號統計，不是投資組合模擬；還沒有基本面、籌碼分數；樣本只有本機的天數。

### 還沒做的部分

- 基本面（§5）、籌碼（§6）：需要月營收、財報（含公告日）、三大法人、融資融券的資料來源。
- 全球風險環境（§2.4）、60／15 分鐘盤中週期（§2.1）。
- 自動下單（§13）：需要券商 API 或 MultiCharts，牽涉真實帳戶，不放在這個 App。
- 投資組合層級：持股相關性、Portfolio Beta、Portfolio Heat。

## 資料怎麼來

| 用途 | 來源 | 說明 |
| --- | --- | --- |
| 推薦／市場／產業／回測／自訂篩選 | 證交所「每日收盤行情」（MI_INDEX，含加權指數）＋ 櫃買中心「上櫃股票行情」 | 一次請求拿到一整天全市場，一年只要 500 多次請求，不用一檔一檔抓 |
| 產業別 | 證交所／櫃買官方產業分類（twstock 整理的清單） | 內建在 App 裡 |
| 今日雷達 | 證交所「基本市況報導」即時報價 | 跟 stock_acc 同一個來源 |

- 第一次打開要先按「開始抓歷史資料」，預設抓最近 400 天（約 280 個交易日，
  200 日均線、52 週新高需要一年左右的資料）。為了不被證交所封鎖，每天間隔 3 秒，
  大約 20 分鐘；由新到舊抓，中途就能先用。
- 抓過的交易日存在本機（一天一個檔），之後只補新的日子；休市日也會記住。
- 除權息還原：用交易所公布的漲跌價差推回參考價，偵測除權息日，把之前的價格
  等比例還原，均線和報酬率不會被除息的假跌幅誤導（§14）。
- 連續 3 天抓不到就會停下來並顯示原因（多半是沒網路或被暫時封鎖）。
- 證交所和櫃買的回應格式以前改過好幾次，所以程式不寫死欄位位置，而是用欄位
  名稱（「證券代號」「收盤價」「成交股數」……）找欄位，新舊格式都認得。

## 開發環境

跟 stock_acc 一樣，這個開發環境（雲端容器）沒有 Android SDK、也不是 Windows，
而且**連不到證交所和櫃買中心**（網路政策擋掉），所以：

- 資料解析是照兩邊公開的回應格式寫、用單元測試（假資料）驗證的，**第一次在
  真的裝置上抓資料時請確認一下有沒有抓到**——「資料」頁會顯示抓到幾天、有沒有
  錯誤訊息。
- `.apk` 和 `.exe` 交給 **GitHub Actions** 編譯，編好會自動發布到 Releases 頁面：

  **下載網址：https://github.com/nmymdf/stock_screener/releases/latest**

  - Android：手機打開上面的網址，點 `stock_screener.apk` 下載後直接安裝
    （第一次要允許「安裝不明來源的 App」）。
  - Windows：下載 `stock_screener-windows.zip`，解壓縮後執行 `stock_screener.exe`。

本機這裡能做、也已經做過的檢查：
```bash
cd app
flutter analyze   # 靜態檢查，沒有錯誤或警告
flutter test      # 指標、篩選條件、資料解析、本機快取、畫面的測試，全數通過
flutter build linux --debug   # 驗證程式碼能真的編譯、啟動
```

### Android 更新保留資料（設定一次就好）

做法跟 stock_acc 完全一樣（金鑰是這個 repo 自己的一把，跟 stock_acc 分開）：

1. **Actions** 分頁 →「**產生 Android 簽章金鑰**」→ **Run workflow**。
2. 下載這次執行的 Artifacts，照裡面 `設定步驟.txt` 把 4 行資料新增成這個 repo
   的 4 個 Secrets（**Settings → Secrets and variables → Actions**）：
   `ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、
   `ANDROID_KEY_PASSWORD`。
3. 刪掉那次執行紀錄和電腦上下載的壓縮檔。
4. 重新觸發「編譯 Windows / Android」。

沒設定之前一樣能編、能用，只是每次更新 Android 版要先移除舊版。

## 架構

```
app/lib/
  models/        日 K（DailyBar，含漲跌價差）、某一天全市場收盤行情（DaySnapshot，含加權指數）
  logic/
    ta.dart      技術指標整條序列：EMA、ATR、ADX/DI、MACD、RSI、布林帶寬、KD、OBV
    adjust.dart  除權息還原
    risk.dart    資金與風險設定、依風險計算張數
    engine/
      market_engine.dart    市場廣度、Market Score、市場狀態
      industry_engine.dart  產業強弱與輪動
      scoring.dart          個股各模組分數（逐項給分）
      signals.dart          A/B/C/D 進場訊號、交易計畫、tick、流動性否決、RS
      analysis.dart         每日分析流程，產生推薦清單
      backtest.dart         回測（跟推薦共用同一組函式）
  services/      抓每日收盤行情（證交所＋櫃買）、抓即時報價
  data/          本機存檔、資料中樞 HistoryStore（背景 isolate 分析）、股票代號表、產業別
  ui/            推薦、市場、產業、回測、工具、個股報告、共用元件與圖表
```

股票代號表（`data/stock_catalog.dart`）、主題、今日雷達的排名邏輯是從 stock_acc 搬過來的，
兩邊之後有更新要記得同步。產業別（`data/stock_industry.dart`）是程式產生的。

## 之後的規劃

- **籌碼**：三大法人、融資融券（證交所／櫃買公開資料，可以用同樣「一天抓一次全市場」的方式）。
- **基本面**：月營收、財報，要照實際公告日使用，避免回測偷看未來。
- **停損停利提醒**：跟 stock_acc 的持股串接，更新報價時提醒碰到停損／移動停利。
- **投資組合層級風控**：用實際持股算產業曝險、Portfolio Heat。
