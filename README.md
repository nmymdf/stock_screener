# 台股選股

台股的選股工具 App，是 [stock_acc（股票記帳）](https://github.com/nmymdf/stock_acc)
README 裡規劃的「個股分析，另一個獨立模組」。技術選股、今日雷達這些功能
獨立成一個 App，放在這個 repo。

跟 stock_acc 一樣用 Flutter 寫，同一份程式碼可以編譯成 **Windows 版**和
**Android 版**。資料只存在裝置本機，不會上傳到任何雲端伺服器。

程式碼在 [`app/`](app) 資料夾。

> **這是機械化的條件篩選和排序，不是投資建議、也不是預測。** 沒有任何指標
> 組合能保證篩出來的股票之後會賺錢，只是幫忙從兩千多檔裡縮小範圍，最終判斷
> 還是要使用者自己來。每個選股畫面上都會顯示這個提醒。

## 功能（第一版）

- **技術選股**：用最近幾個月的每日收盤行情算技術指標，篩選全部上市櫃股票
  （約 2300 檔）。
  - 條件（可以任意組合，勾選的條件之間是「而且」）：多頭排列（收盤 > 5 日 >
    20 日 > 60 日線）、站上 20／60 日線、5 日線黃金交叉 20 日線、RSI(14) 區間、
    收盤創 N 日新高、量比（今天量 ÷ 前 20 日均量）、今日漲幅、20 日均量下限
    （過濾冷門股）、股價區間。
  - 常用條件一鍵套用：多頭排列、帶量突破、黃金交叉、RSI 超賣、量能爆發。
  - 每一檔都附上「符合哪些條件」的理由，可以依今日漲幅、量比、近 20 日漲幅、
    RSI 排序。條件會自動記住，下次打開還在。
- **今日雷達**：沿用 stock_acc 的「選股雷達」，抓候選股（熱門股/ETF 候選池，
  或全市場）當下的即時報價，用今日漲幅、量能、股價貼近今日高點排名。
- **個股頁**：收盤價走勢圖（含 20／60 日線）、各項指標數字、最近 10 個交易日
  的開高低收量。
- **資料**：歷史資料同步狀態、回看天數（90～270 天）、本機存放位置、清除快取。
- **畫面自動適應**：視窗寬（電腦）時左邊側邊選單，窄（手機）時底部分頁列。

## 資料怎麼來

| 用途 | 來源 | 說明 |
| --- | --- | --- |
| 技術選股 | 證交所「每日收盤行情」（MI_INDEX）＋ 櫃買中心「上櫃股票行情」 | 一次請求拿到一整天全市場，所以 60 多個交易日只要 100 多次請求，不用一檔一檔抓 |
| 今日雷達 | 證交所「基本市況報導」即時報價 | 跟 stock_acc 同一個來源 |

- 第一次打開要先按「開始抓歷史資料」，預設抓最近 120 天。為了不被證交所
  封鎖（太密集的請求會被暫時擋 IP），每天間隔 3 秒，大約 6～8 分鐘。
- 抓過的交易日存在本機（一天一個檔），之後只補新的日子；休市日也會記住，
  不會一直重抓。中途停掉也沒關係，已抓到的先能用，下次從缺的地方繼續。
- 連續 3 天抓不到就會停下來並顯示原因（多半是沒網路或被暫時封鎖）。
- 證交所和櫃買的回應格式以前改過好幾次，所以程式不寫死欄位位置，而是用欄位
  名稱（「證券代號」「收盤價」「成交股數」……）找欄位，新舊格式都認得。

## 開發環境

跟 stock_acc 一樣，這個開發環境（雲端容器）沒有 Android SDK、也不是 Windows，
而且**連不到證交所和櫃買中心**（網路政策擋掉），所以：

- 資料解析是照兩邊公開的回應格式寫、用單元測試（假資料）驗證的，**第一次在
  真的裝置上抓資料時請確認一下有沒有抓到**——「資料」頁會顯示抓到幾天、有沒有
  錯誤訊息。
- `.apk` 和 `.exe` 交給 **GitHub Actions** 編譯：到 repo 的 **Actions** 分頁，
  找「編譯 Windows / Android」最新一次執行，下面的 **Artifacts** 有
  `stock_screener-windows`（解壓縮後執行 `stock_screener.exe`）和
  `stock_screener-android`（`app-release.apk`）。

本機這裡能做、也已經做過的檢查：
```bash
cd app
flutter analyze   # 靜態檢查，沒有錯誤或警告
flutter test      # 指標、篩選條件、資料解析、本機快取、畫面的測試，全數通過
flutter build linux --debug   # 驗證程式碼能真的編譯、啟動
```

### Android 更新保留資料（設定一次就好）

做法跟 stock_acc 完全一樣（金鑰是這個 repo 自己的一把，跟 stock_acc 分開）：

1. **Actions** 分頁 →「**產生 Android 簽章金鑰**」→ **Run workflow**。
2. 下載這次執行的 Artifacts，照裡面 `設定步驟.txt` 把 4 行資料新增成這個 repo
   的 4 個 Secrets（**Settings → Secrets and variables → Actions**）：
   `ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、
   `ANDROID_KEY_PASSWORD`。
3. 刪掉那次執行紀錄和電腦上下載的壓縮檔。
4. 重新觸發「編譯 Windows / Android」。

沒設定之前一樣能編、能用，只是每次更新 Android 版要先移除舊版。

## 架構

```
app/lib/
  models/     日 K 資料（DailyBar）、某一天全市場的收盤行情（DaySnapshot）
  logic/      純計算：技術指標（均線、RSI、量比、新高、黃金交叉）、
              技術選股的條件與篩選、今日雷達的排名（都有單元測試）
  services/   抓每日收盤行情（證交所＋櫃買）、抓即時報價
  data/       本機存檔（JSON）、資料中樞 HistoryStore、內建股票代號表
  ui/         主題、共用元件、導覽殼、技術選股／今日雷達／個股／資料頁
```

股票代號表（`data/stock_catalog.dart`）和主題、今日雷達的排名邏輯是從
stock_acc 搬過來的，兩邊之後有更新要記得同步。

## 之後的規劃

- **回測**：用同一份每日收盤行情，驗證某組條件過去篩出來的股票之後 N 天的
  表現（勝率、平均報酬）。
- **停損停利提醒**：設定價位，更新報價時提醒。
- 跟 stock_acc 串接：把持股、關注清單帶進來一起篩選。
