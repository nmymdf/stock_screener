# 台股選股

台股的**長期投資**選股 App，是 [stock_acc（股票記帳）](https://github.com/nmymdf/stock_acc)
README 裡規劃的「個股分析，另一個獨立模組」。

跟 stock_acc 一樣用 Flutter 寫，同一份程式碼可以編譯成 **Windows 版**和 **Android 版**。
持股資料只存在裝置本機，不會上傳；市場資料由 GitHub Actions 每天整理成資料包，App 只下載。

程式碼在 [`app/`](app) 資料夾。

> **僅供參考，不是投資建議；投資盈虧請自行負責。** 這是依公開資料、固定規則算出來的參考，不是預測；
> 過去的回測成績不代表未來。App 抬頭每個畫面都會顯示這句話，第一次打開要按「我了解並同意」，「工具 → 免責聲明」有完整內容。
> 這個 App 只在朋友之間免費分享；如果要收費提供投資建議，依法需要投資顧問執照。

## 功能

目前版本：**v5.0.0**——改成「**候選名單由你挑、持股逐檔健檢**」，不再替你配比例。

**先說實話**：用 2014–2026 的真實資料檢驗，一檔上市股票抱一年贏 0050 的機會只有三成多（0050 裡的台積電漲太多）。
任何選股名單都很難長期贏 0050；名單的用處是幫你挑、幫你避雷，不是保證贏。下面每個數字都是規則先定好、再檢驗出來的。

| 部分 | 內容 | 檢驗結果（扣成本） |
| --- | --- | --- |
| **強勢成長名單** | 趨勢模板（Minervini、O'Neil）＋月營收：多頭排列、接近一年高點、一年漲幅前 30%、近 3 月營收年增 20% 以上、每天成交 2 億以上、沒有地雷；最多 10 檔，同產業最多 2 檔；跌破 50 日線就走 | 抱 6 個月：平均 +13.3%（0050 +10.7%）、賺錢 62%、贏 0050 48%。2020 以後有用，2014–2019 輸 0050；抱一年大多輸 |

### 評分：六大類分數（用來判斷地雷）

每月檢視日對每檔上市普通股計算，換成全市場百分位：

| 類別 | 權重 | 內容 |
| --- | --- | --- |
| 動能趨勢 | 20% | 近 12 個月（扣最近 1 個月）與近 6 個月含息報酬、站上年線程度（超過 30% 不再加分）、年線方向 |
| 營收成長 | 20% | 近 3 個月營收年增、近 12 個月成長月數、近 12 個月累計年增、成長加速（年增率用同一份月報的去年同月營收算） |
| 獲利品質 | 20% | ROE（股價淨值比 ÷ 本益比，近四季）高低與 3 年穩定度、EPS 一年來成長；虧損排最後 |
| 價值股利 | 20% | 本益比在自己 5 年歷史的位置、盈餘殖利率、現金殖利率（**殖利率陷阱**不加分）、近 5 年配息年數 |
| 法人籌碼 | 10% | 外資、投信近 60 日買賣超佔成交量比例 |
| 穩定度 | 10% | 一年波動度、一年最大跌幅 |

- 權重事先決定，不拿回測結果去調。
- 警示：短期過熱、年線下彎、營收衰退、虧損、殖利率陷阱、獲利大減、成交量太小。

### 回測怎麼避免自己騙自己

- **不偷看未來**：發行股數、本益比、殖利率用當天公布的；月營收保守假設 11 日以後才知道；股價只用當天以前的；
  除權息照證交所的參考價（總報酬）；**減資、變更面額**照證交所的恢復買賣參考價接起來；國際指標只用台股前一天以前的美國收盤。
- 規則只用 2014–2019 年決定，2020 以後是事先沒看過的檢驗；及格標準事先寫好，不事後改。
- 檢視日收盤決定、隔天收盤成交；扣手續費 0.1425%、證交稅 0.3%、滑價 0.1%。
- 名單包含之後下市的股票（沒有存活者偏差）；跟**加權股價報酬指數（含息）**比，不是只跟價格指數比。
- 附兩段期間、大跌期間、地雷成績單、因子研究，檢查是不是運氣或剛好調到某個數字。
- 最新一天（現在）的評分則用手上所有已公布的資料。

### 持股的兩組：手動／模擬、stock_acc 記帳

- **手動／模擬**：每個人都有。自己輸入持股，或在個股報告按「我已進場」；也可以放沒有真的買、
  只想照系統建議追蹤的模擬單。每一筆買進／賣出紀錄都可以點開修改日期、價格、股數，或刪除；
  持股卡片的「⋮」選單可以修改設定、記錄賣出、加碼、刪除整筆。
- **stock_acc 記帳**（只有電腦版、而且這台電腦有 [stock_acc](https://github.com/nmymdf/stock_acc) 的資料才會出現）：
  - 讀取 `%APPDATA%\com.archiekuo\stock_acc\` 裡的交易紀錄——**只讀不寫**，不會修改 stock_acc，也不會傳到任何地方。
  - 打開 App 時讀一次；在 stock_acc 記完帳，回來按「同步 stock_acc」更新。
  - 所有群體、人、券商帳戶的同一檔股票合併成一筆；從 0 股變成有股數就是一筆新持股，賣到 0 就結案。
    損益用 stock_acc 的實際手續費和證交稅。
  - 買賣紀錄以 stock_acc 為準（在這裡唯讀）；持有方式、停損、備註可以在這裡改，重新同步不會洗掉。
  - 朋友的電腦沒有 stock_acc 的資料，這一組整個隱藏，畫面跟一般版本一樣。
- 兩組同時存在、各自計算；另一組有需要處理的持股時，持股頁會提醒。
- **長期持有者的用法**：stock_acc 同步進來的股票預設用「長期」規則（可在「持股設定」改成波段、短線）。
  長期的狀態只有四種：**健康、觀察、轉弱、考慮減碼**，只在狀態改變那天記一筆，不用每天盯。
- **追蹤起點**：已經持有兩週以上才加進來的股票，從第一次同步（或加入）那天開始判斷，不倒推過去的走勢，
  也就不會一開始就一堆「應已出場」；損益仍以實際成本計算。任何一檔都可以按「從今天重新開始追蹤」。
- **只看例外**：今日摘要寫「今天需要注意 N 檔，其他 M 檔正常」，正常的預設收合；只列離關鍵價位 3% 以內的；
  可以切換成表格（狀態、損益、離關鍵價、健康度一檔一行）；另有「本週報告」整理這週狀態變差、好轉、漲跌最多的。

### 持股追蹤

- **新增持股**：自己輸入（代號、日期、價格、股數），或在個股報告按「我已進場」，自動帶入推薦時的停損、目標和理由。
- **持有方式**決定停損與出場規則：

  | 方式 | 停損 | 出場 | 時間停損 |
  | --- | --- | --- | --- |
  | 短線（1～3 週） | 進場價 − 2 ATR（或推薦停損） | +1R 保本；2R 先賣一半，剩下「最高價 − 3 ATR」移動停利 | 10 天沒有 +1R |
  | 波段（1～3 個月） | 進場價 − 2.5 ATR（或推薦停損） | +1R 保本，之後移動停利一路抱住 | 無 |
  | 長期（一季以上） | 持有期間最高收盤回落 25%（可改 20～35%）→「考慮減碼」 | 收盤連續 3 天在年線之下且年線下彎 →「轉弱」；跌破年線、回落一半、健康度下降只是「觀察」 | 無 |
  | 自己設定 | 自己填 | 碰到自己填的目標價 | 無 |

- **每天的持續建議**：停損出場、出場（移動停利、保本、時間停損、長期趨勢轉弱）、應已出場・未處理（第 N 天）、
  先賣一半（到 2R，或持有理由大多失效）、可以加碼、續抱但注意、續抱。需要處理的排最上面。
- **每日追蹤紀錄**：從買進到賣出每個交易日一筆——收盤、損益（% 和 R）、停損（上調會標出）、
  當天發生的事（+1R 保本、停損上調、創新高、跌破均線、量價異常、市場轉變、持有週期升降級、
  你的買賣）、建議和原因、健康度。上面是持有摘要，賣完後有結案摘要（預估持有期間 vs 實際）。
- **持有理由健康度**：每天檢查買進理由還成立嗎（守住 20 日線／季線、趨勢、贏過大盤、量價、動能、市場、
  離停損緩衝）；連續兩天低於 40，跌破停損前就先建議減碼一半。
- **明日劇本**：收盤在哪個價位該停損、警戒、續抱、+1R 保本、加碼。
- **加碼時機**：+1R 之後、回測 20 日線不破或整理後再突破，附價格與狀態；虧損中禁止。
- **持有週期升降級**：只有已經獲利 +1R 才會升級；虧損中不能把短線改成更長的持有方式（會擋下）。
- **紀律**：出場訊號出現後準時處理、晚處理（多賠多少）、還沒處理、提前賣出，統計準時率。
- 從買進那天一天一天模擬規則，停損只會往上調；除權息後成本跟著還原，不會被假跌幅觸發。
- **只加贏家**：已經賺 ≥ 1R、健康度夠、出現新訊號或整理後再突破才提示可以加碼；虧損時加碼會警告「禁止向下攤平」，要勾選確認才能記錄。
- 損益扣手續費 0.1425%（最低 20 元）和證交稅；全部賣出後列入交易紀錄（勝率、平均賺賠、已實現合計）。
- 只是提醒，不會自動下單；判斷用收盤價。

## 開發環境

跟 stock_acc 一樣，這個開發環境（雲端容器）沒有 Android SDK、也不是 Windows，
而且**連不到證交所和櫃買中心**（網路政策擋掉），所以：

- 長期資料包由 GitHub Actions 抓（GitHub 的伺服器連得到證交所、觀測站），解析器用 CI 的試抓紀錄驗證過新舊格式；
  每日行情的直接抓取（今天 15:00 以後的收盤）在真的裝置上執行。
- `.apk` 和 `.exe` 交給 **GitHub Actions** 編譯，編好會自動發布到 Releases 頁面：

  **下載網址：https://github.com/nmymdf/stock_screener/releases/latest**

  - Android：手機打開上面的網址，點 `stock_screener.apk` 下載後直接安裝
    （第一次要允許「安裝不明來源的 App」）。
  - Windows（建議）：下載 `stock_screener_setup.exe`，點兩下安裝（不需要管理員權限），
    會在桌面和開始功能表建立「台股選股」捷徑。更新時下載新的安裝檔再執行一次即可。
  - Windows（免安裝版）：下載 `stock_screener-windows.zip`，在檔案上按右鍵「解壓縮全部」，
    執行解壓縮出來的 `stock_screener.exe`。不要在壓縮檔裡直接點 exe，會出現「找不到
    flutter_windows.dll」。
  - 長期資料包、每日行情、持股、設定存在 `%APPDATA%\com.archiekuo\stock_screener`，更新或重新安裝都不會不見。

本機這裡能做、也已經做過的檢查：
```bash
cd app
flutter analyze   # 靜態檢查，沒有錯誤或警告
flutter test      # 資料包解析、長期因子、組合回測、汰弱留強、指標、本機快取、畫面的測試，全數通過
flutter build linux --debug   # 驗證程式碼能真的編譯、啟動
```

### Android 更新保留資料（設定一次就好）

做法跟 stock_acc 完全一樣（金鑰是這個 repo 自己的一把，跟 stock_acc 分開）：

1. **Actions** 分頁 →「**產生 Android 簽章金鑰**」→ **Run workflow**。
2. 下載這次執行的 Artifacts，照裡面 `設定步驟.txt` 把 4 行資料新增成這個 repo
   的 4 個 Secrets（**Settings → Secrets and variables → Actions**）：
   `ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、
   `ANDROID_KEY_PASSWORD`。
3. 刪掉那次執行紀錄和電腦上下載的壓縮檔。
4. 重新觸發「編譯 Windows / Android」。

沒設定之前一樣能編、能用，只是每次更新 Android 版要先移除舊版。
